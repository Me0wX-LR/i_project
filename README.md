# 流變計畫｜Project Ignis — 對外測試版

《流變計畫》Project Ignis 的靜態建置，供外部測試用。

繁體中文、日系漫畫風的 72 小時生存模擬。你是被世界歸類為癌細胞的**超越者**，被裏八咫丟進封閉城市，必須在刻印排名、流變侵蝕與人際羈絆之間活到閉幕。

## 遊玩

直接開啟 Pages 網址，或在瀏覽器打開 `index.html`。不需要安裝、不需要後端。

- 點選行動方針，時間自動推進；事件發生時時間暫停。
- 空白鍵暫停／繼續；Esc 關閉選單與抽屜。
- 支援滑鼠、觸控與鍵盤；手機單欄、桌面三欄。

## 一局的長度

72 小時遊戲內時間，可 1×–8× 加速。九種結局。

## 內容提醒

本作包含暴力、死亡、精神侵蝕與制度性暴力。角色、城市與機構均為虛構。

## 建置

此目錄為 `npm run build` 的產物（`dist/`），非原始碼。原始碼在開發者的遊戲專案工作區內。
